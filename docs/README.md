## 2. 推荐阅读顺序

**想快速体验**：根目录 [README](../README.md) → 运行 → 看界面截图。

**想理解实现**：

1. [01-需求分析](01-需求分析.md)：先看要解决什么问题
2. [02-技术方案](02-技术方案.md)：再看架构、数据模型与三个核心算法
3. 源码：`util/UrgencyCalculator` → `util/GradeCalculator` → `service/ReminderPlanner` → `ui/MainFrame`
4. [04-测试与验收](04-测试与验收.md)：对照用例理解边界

**准备答辩**：

1. [05-课程设计交付说明](05-课程设计交付说明.md) 第 1、2 节（要求对照与技术点映射）
2. [05](05-课程设计交付说明.md) 第 4 节（答辩提纲与 10 个预设问答）
3. [04](04-测试与验收.md) 第 8 节（5 分钟演示脚本）
4. [02](02-技术方案.md) 第 5 节（公式与算例，确保能徒手推导）

## 5. 文档生成与校验

- 架构图、ER 图、时序图、甘特图使用 Mermaid，GitHub / Gitee 均可直接渲染
- 界面截图由程序自身渲染：

```bash
java -jar target/coursework-tracker-1.0.0.jar --seed-demo
java -jar target/coursework-tracker-1.0.0.jar --screenshot=docs/assets/main-light.png
```

- 提交前自查：链接可点、代码块闭合、表格列数一致、数字与代码一致

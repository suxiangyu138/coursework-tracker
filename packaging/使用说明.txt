一、运行
1. 安装 Java 17 或更高版本。
2. 双击「启动作业哨兵.bat」，或直接双击 coursework-tracker.jar。
3. 首次启动会询问是否生成示例数据，也可以稍后在「文件 → 生成示例数据」中生成。

二、数据位置
- 数据库：data/coursework.db
- 自动备份：data/backup/coursework-YYYYMMDD.db（保留最近 7 份）
- 日志：logs/app.log
更新或替换 jar 不会删除 data/，作业、成绩和 API Key 都会保留。

三、更新
「帮助 → 检查更新」选择新版本 jar：
- 更新前自动备份数据库
- 旧版程序保留为 update-backup.jar
- 只替换 jar，data/ 不动，更新后自动重启

四、AI 助手（可选）
「设置 → AI 助手」填写 DeepSeek API Key 并保存。
DeepSeek 当前可用模型：deepseek-flash（默认）、deepseek-v4-pro。
未启用 AI 时程序不发起任何网络请求。

五、隐私
数据保存在本机；启用 AI 后，对话内容与工具参数会发送到你配置的 DeepSeek 接口。
不要把 data/ 目录发给别人（其中包含 API Key）。
